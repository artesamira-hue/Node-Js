========================================

========================================

And:
========================================
   npm install --save-dev nodemon
========================================

What each package does
Package          	Purpose
express	            Creates the backend/server
mongoose	        Connects Node.js to MongoDB
cors	            CORS allows your frontend (localhost:5157) to communicate with your backend(localhost:8000) even though they use different ports.
                    Frontend → 5157
                    Backend → 8000
                    CORS → allows communication between them ✅
                    But if the backend is not running, CORS won't fix that. 
dotenv	            Reads variables from .env
bcryptjs	        Hashes and checks passwords
jsonwebtoken	    Creates/verifies JWT tokens
nodemon	            Automatically restarts server during development

5. Create Express server

We created:
========================================
index.js
========================================

This is the entry point of our backend.
===============================================
const express = require("express");
const cors = require("cors");
const dotenv = require("dotenv");

const connectDB = require("./config/db");
const authRoutes = require("./routes/authRoutes");

dotenv.config();

const app = express();

connectDB();

app.use(cors());
app.use(express.json());

app.get("/", (req, res) => {
  res.send("Server is running");
});

app.use("/api/auth", authRoutes);

const PORT = process.env.PORT || 5000;

app.listen(PORT, () => {
  console.log(`Server running on port ${PORT}`);
});
====================================================

Important things happening here
====================================================
dotenv.config(); 
====================================================
Loads .env.

====================================================
connectDB();
====================================================
Connects MongoDB.

====================================================
app.use(cors());
====================================================
Allows frontend communication.

====================================================
app.use(express.json());
====================================================
Allows Express to understand JSON request bodies.

====================================================
app.use("/api/auth", authRoutes);
====================================================
Connects our authentication routes.

9. Login API

For login, we receive:
====================================================
{
  "email": "samira@gmail.com",
  "password": "123456"
}
====================================================

First:
====================================================
const user = await User.findOne({ email });
====================================================
We find the user in MongoDB.

Then:
====================================================
const isPasswordCorrect = await bcrypt.compare(
  password,
  user.password
);


This compares:
User's entered password
          ↓
       bcrypt
          ↓
Password stored in DB
====================================================

If correct, we create a JWT:
====================================================
const token = jwt.sign(
  {
    userId: user._id,
    email: user.email,
  },
  process.env.JWT_SECRET,
  {
    expiresIn: "1h",
  }
);
====================================================

Then return:

{
  "message": "Login successful",
  "token": "eyJhbGciOiJIUzI1Ni...",
  "user": {
    "id": "...",
    "name": "Samira",
    "email": "samira@gmail.com"
  }
}

11. Why /api/auth?

In index.js:
====================================================
app.use("/api/auth", authRoutes);
====================================================

And in authRoutes.js:
====================================================
router.post("/register", registerUser);
router.post("/login", loginUser);
====================================================

Express combines them.

Therefore:
/api/auth + /register
        ↓
POST /api/auth/register

and:

/api/auth + /login
        ↓
POST /api/auth/login

So our APIs are:

POST http://localhost:5000/api/auth/register

POST http://localhost:5000/api/auth/login

12. JWT

JWT is used to identify an authenticated user.

The flow is:

Email + Password
       ↓
    MongoDB
       ↓
bcrypt.compare()
       ↓
   Correct?
       ↓
      YES
       ↓
   jwt.sign()
       ↓
     Token

The secret:

process.env.JWT_SECRET

is used to sign the token.

Later we'll use the same secret to verify it.
